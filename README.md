# UU 远程校园网直连工具 (Windows 版)

解决校园网环境下 **UU 远程** 无法登录或连接超时的问题。

## 工具原理与特点
* **纯本地直连**：基于开源项目 [GoodbyeDPI](https://github.com/ValdikSS/GoodbyeDPI)，仅在本地对发起的 TLS 握手数据包进行底层分片，**不经过任何第三方服务器、不消耗额外流量、不涉及翻墙**。
* **零网络残留**：不修改 Windows 系统代理或注册表，关闭窗口或卸载服务后网络立刻恢复原状。

---

## 使用步骤

### 1. 解压运行
将压缩包**完整解压**到一个纯英文路径（例如桌面），右键或直接双击运行 **`UU.bat`**。

*(注：请勿直接在压缩包预览窗口里双击运行，否则会找不到路径。)*

### 2. 放行权限与安全提示
* **管理员权限**：运行时会弹出“用户账户控制”询问是否允许更改设备，请点击 **“是”**（加载底层网络分片驱动必需）。
* **SmartScreen 提示**：如果弹出蓝色窗口“Windows 已保护你的电脑”，点击 **“更多信息” -> “仍要运行”**。
* **杀毒软件误报**：如果 Windows 安全中心、火绒或 360 提示拦截 `WinDivert64.sys`，请选择 **“允许”** 或 **“信任”**（这是开源的网络数据包过滤驱动，属于正常现象）。

### 3. 选择运行模式
脚本会自动从 GitHub 下载核心组件并解压到 `C:\goodbyedpi`，随后进入操作菜单：

* **`[1]` 临时启动（适合主控端 / 临时使用）**
  开启本地分片，保持弹出的黑色窗口**不要关闭**，此时即可正常打开 UU 远程登录。不用时直接关闭黑框即自动停止。
* **`[2]` 安装开机自启服务（推荐宿舍被控端使用）**
  将分片程序注册为 Windows 后台服务并立即启动。设置完成后**可以关闭黑框**，以后电脑重启也会在后台自动静默生效，适合无人值守的宿舍电脑。
* **`[3]` 卸载开机自启服务**
  如果不再需要后台自启，运行脚本选 `3` 即可彻底停止并移除后台服务。

## 常见问题

**Q：提示 `[错误] 下载失败，可能是校园网暂时连不上 GitHub` 怎么办？**
A：校园网直连 GitHub 偶尔会抽风超时。可以多试两次；如果一直下载失败，请用手机热点或能上 GitHub 的网络下载 `goodbyedpi-0.2.3rc3-2.zip`，将压缩包重命名为 **`goodbyedpi.zip`**，手动放进 **`C:\goodbyedpi\`** 文件夹中，再重新双击运行脚本即可自动跳过下载直接解压。

**Q：开启后会影响正常上网或打游戏吗？**
A：不会。数据包依然是直接发往目标服务器，对日常网页浏览、校内网访问及联机游戏延迟无影响。如果极个别网银或政企网站出现加载异常，临时关闭黑框（或选 `3` 停用服务）即可。
