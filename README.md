# UU 远程校园网直连工具使用说明 (Windows & Android)

本方案用于解决校园网环境下 **UU 远程** 无法登录或连接超时的问题。

> ### ⚠️ 重要说明：这不是“翻墙”工具！
> 1. **100% 国内直连**：本方案基于开源网络数据包工具（Windows 端 `GoodbyeDPI` / Android 端 `ByeByeDPI`），仅在设备本地对发出的 TLS 握手数据包进行切分（分片），**不连接任何境外或第三方代理服务器、不消耗额外流量、不涉及任何翻墙行为**。
> 2. **流量直达网易**：所有网络请求的目标地址依然是网易在国内的官方服务器，关闭工具或退出后台后网络立即恢复原状。

---

## 一、 Windows 电脑端（支持主控端 / 宿舍被控端）

### 1. 解压运行
将压缩包**完整解压**到一个纯英文路径（例如桌面），双击运行 **`UU远程绕过配置.bat`**。
*(注：请勿直接在压缩包预览界面里双击运行，否则会提示找不到路径。)*

### 2. 放行权限与安全提示
* **管理员权限**：运行时会弹出“用户账户控制”询问是否允许更改设备，点击 **“是”**（加载底层网络分片驱动必需）。
* **SmartScreen 提示**：如果弹出蓝色窗口“Windows 已保护你的电脑”，点击 **“更多信息” -> “仍要运行”**。
* **杀毒软件误报**：如果 Windows 安全中心、火绒或 360 提示拦截 `WinDivert64.sys`，请选择 **“允许”** 或 **“信任”**（这是开源的网络数据包过滤驱动，属于正常现象）。

### 3. 选择运行模式
脚本会自动下载核心组件并解压到 `C:\goodbyedpi`，随后进入操作菜单：
* **`[1]` 临时启动（适合临时使用）**：开启本地分片，保持弹出的黑色窗口**不要关闭**，此时即可正常打开 UU 远程登录。不用时直接关闭黑框即自动停止。
* **`[2]` 安装开机自启服务（推荐宿舍被控端使用）**：将分片程序注册为 Windows 后台服务并立即启动。设置完成后**可以关闭黑框**，以后电脑重启也会在后台自动静默生效，适合无人值守的宿舍电脑。
* **`[3]` 卸载开机自启服务**：不再需要时，运行脚本选 `3` 即可彻底停止并移除后台服务。

## 二、 Android 手机 / 平板端（支持主控端）

### 1. 下载与安装
1. 前往 GitHub 搜索开源项目 **`romanvht/ByeByeDPI`**，进入 **Releases** 页面，下载最新的 **`ByeByeDPI-v1.8.2-arm64-v8a-release.apk`** 并安装（若提示不兼容，改下 `universal` 通用版）。
2. *(如果通过微信/QQ 传输文件被自动改成了 `.apk.1`，在手机“文件管理”中重命名删掉 `.1` 即可正常安装。)*

### 2. 核心参数配置
打开 **ByeByeDPI**，**先不要点连接**，点击右上角 **齿轮图标 (Settings)** 进行如下设置：
1. **更改 DNS**：找到 **DNS** 选项，将默认的 `8.8.8.8` 修改为国内阿里 DNS **`223.5.5.5`**（防止校园网连不上国外 DNS 导致解析超时）。
2. **开启命令行模式**：打开 **Use command line settings（使用命令行设置）** 开关。
3. **填入分片参数**：点击进入 **Command line arguments（命令行参数）**，输入以下内容并保存：
