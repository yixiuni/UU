# UU 远程校园网直连工具使用说明 (Windows & Android)

本方案用于解决校园网环境下 **UU 远程** 无法登录或连接超时的问题。

> ### ⚠️ 重要说明：这不是“翻墙”工具！
> 1. **100% 国内直连**：本方案基于开源网络数据包工具（Windows 端 `GoodbyeDPI` / Android 端 `ByeByeDPI`），仅在设备本地对发出的 TLS 握手数据包进行切分（分片），**不连接任何境外或第三方代理服务器、不消耗额外流量、不涉及任何翻墙行为**。
> 2. **流量直达网易**：所有网络请求的目标地址依然是网易在国内的官方服务器，关闭工具或卸载服务后网络立即恢复原状。

---

## 一、 Windows 电脑端（支持主控端 / 宿舍被控端）

新版脚本默认采用**定向模式**（仅对 `163.com`、`netease.com` 及其子域名生效），大幅降低对 **CC Switch** 等开发/代理工具的干扰，并支持从旧版安全升级。

### 1. 解压与运行
将压缩包**完整解压**到一个纯英文路径（例如桌面），双击运行 **`UU.bat`**。
*(注：请勿直接在压缩包预览窗口里双击运行，否则会提示找不到路径。)*

### 2. 放行权限与安全提示
* **管理员权限**：弹出“用户账户控制”询问时，点击 **“是”**（加载底层网络分片驱动必需）。
* **SmartScreen 提示**：若弹出蓝色窗口“Windows 已保护你的电脑”，点击 **“更多信息” -> “仍要运行”**。
* **杀毒软件误报**：若 Windows 安全中心、火绒或 360 提示拦截 `WinDivert64.sys`，请选择 **“允许”** 或 **“信任”**（这是开源的网络数据包过滤驱动，属正常现象）。

### 3. 菜单功能说明
首次启动会自动下载并校验核心文件（`goodbyedpi.exe`、`WinDivert.dll`、`WinDivert64.sys`）至 `C:\goodbyedpi`，随后根据需求输入数字并回车：

* **`[1]` 临时启动 - 定向模式（推荐）**
  仅处理网易系域名，降低对 CC Switch 等软件的影响。保持弹出的黑色窗口**不要关闭**即可登录 UU 远程，不用时直接关窗停止。
  *(注：启动前会自动停止已运行的旧后台服务，并检测是否已有其他临时运行窗口，防止多实例冲突。)*
* **`[2]` 安装/更新开机自启 - 定向模式（推荐宿舍被控端）**
  注册为 Windows 后台自启服务，电脑重启后自动静默生效。
  * **老用户安全升级**：支持原地更新旧版服务，内置 **22 秒驱动稳定性校验**，若更新失败会自动回滚恢复原有服务，防止宿舍被控端失联。
* **`[3]` 卸载开机自启服务（离线可用）**
  彻底停止并移除后台服务（兼容旧版），无需联网即可执行。
* **`[4]` 临时启动 - 全局模式（备选）**
  仅当定向模式失效时作为备选使用。全局模式可能会干扰 CC Switch 等工具，不用时请及时关闭窗口。

## 二、 Android 手机 / 平板端（主控端）

### 方式一：直接用手机流量（最简便，优先推荐）
* 手机或插卡平板做主控端时，如果流量充足，**直接关闭 Wi-Fi 改用 4G/5G 蜂窝网络**即可秒连并远程控制，完全无需安装任何额外软件。
* 只有设备**必须连接校园网 Wi-Fi**（例如无卡 Wi-Fi 版平板，或手机流量吃紧）时，再按下方方式二配置。

### 方式二：校园网 Wi-Fi 环境下使用 ByeByeDPI（纯本地直连）

#### 1. 下载与安装
1. 前往 GitHub 搜索开源项目 **`romanvht/ByeByeDPI`**，进入 **Releases** 页面，下载最新的 **`ByeByeDPI-v1.8.2-arm64-v8a-release.apk`** 并安装（若提示与设备不兼容，改下 `universal` 通用版）。
2. *(注：若通过微信或 QQ 传输文件被自动加了 `.1` 后缀变成 `.apk.1`，在手机“文件管理”中重命名删掉 `.1` 即可安装。)*

#### 2. 核心参数配置
打开 **ByeByeDPI**，**先不要点连接**，点击右上角 **齿轮图标 (Settings)** 进行以下设置：
1. **更改 DNS**：找到 **DNS** 选项，将默认的 `8.8.8.8` 改为国内阿里 DNS **`223.5.5.5`**（防止校园网连不上国外 DNS 导致解析超时）。
2. **开启命令行模式**：打开 **Use command line settings（使用命令行设置）** 开关。
3. **填入分片参数**：点击进入 **Command line arguments（命令行参数）**，输入以下内容并保存：
